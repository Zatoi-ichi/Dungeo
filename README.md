# Dungeon

Dungeon é um jogo de batalha feito com HTML, CSS e JavaScript. Nele, o jogador controla um herói que precisa derrotar um Slime.

## Funcionalidades

- Atacar o Slime.
- Recuperar vida usando cura.
- Recuperar fadiga usando comida.
- Acompanhar as barras de vida e fadiga.
- Animações de ataque, dano, cura, vitória e derrota.
- Reiniciar a partida.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como executar

1. Baixe ou clone o projeto.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html` no navegador.

Também é possível executar usando a extensão Live Server do VS Code.

## Como jogar

- **Atacar:** causa dano ao Slime e consome fadiga.
- **Curar:** recupera parte da vida.
- **Comida:** recupera fadiga.

Derrote o Slime para vencer a batalha!
